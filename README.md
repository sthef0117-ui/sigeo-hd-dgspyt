# SIGEO-HD DGSPYT
### Sistema de Geointeligencia Operativa HD - DGSPYT & C5

Plataforma de geointeligencia operativa, analítica táctica de homicidios dolosos y geocodificación nativa Windows Maps para la Dirección General de Seguridad Pública y Tránsito (DGSPYT) y la Coordinación C5.

## Componentes
- **Dashboard Interactivo**: Index principal en HTML/JS standalone.
- **Geocodificador NLP Windows Maps**: Extractor de direcciones a partir de descripciones textuales.
- **Auditoría de Decesos & Suicidios**: Módulo de análisis tipológico.
- **Mapa Táctico Multicapa**: Heatmap e integración con subbanca al 911.
